# Laboration 2 | Backend-baserad webbutveckling 

Denna lösning för laboration 2 har användaren möjlighet att lägga till sina arbetslivserfarenheter och spara dem i en lista. För att uppnå detta 
så har ett API/Webbtjänst skapats som kan ta emot, lagra, uppdatera och radera data från en databas. När användaren fyller i formuläret med sina arbeten 
så skickas ett POST-anrop för att lägga till den informationen i databasen. Listan som skapas på webbplatsen med alla arbeten hämtar data från databasen med
ett GET-anrop och renderar ut alla jobb-poster den får från databasen. Man kan även radera data från databasen genom ett DELETE-anrop till webbtjänsten. 

Lösningen ger därför användaren möjlighet att lägga till sina arbetslivserfarenheter i ett formulär och kan se dessa arbeten samlade i en lista. Med hjälp av en 
papperskorgssymbol så har användaren möjlighet att radera ett arbete från listan.
